# Карточка модели NDVI v8

## Назначение

Восстановление `primary_ndvi` для строк тестового набора, где
`is_synthetic_gap=True`.

## Подтверждённый результат

- replacement leaderboard RMSE: **0.0712**;
- предыдущая leak-free v7: 0.0720;
- улучшение v8: 0.0008 RMSE.

## Состав

- mask-safe временные, сезонные, погодные и cross-field признаки;
- восстановленный donor context из опубликованной разметки снятого test;
- prior: CatBoost + LightGBM;
- source-gated ветка: три LightGBM expert и CatBoost source classifier;
- фиксированный blend: 20% prior, 80% source-gated.

## Почему выбран этот вариант

Восстановленный контекст улучшил locked analog19 validation с 0.062660 до
0.060976 и затем дал подтверждённый прирост на replacement leaderboard. Это
содержательная интерпретация опубликованных данных как временных доноров, а не
прямое дообучение на раскрытых ответах.

## Ограничения

- перенос прироста с analog19 на replacement test оказался слабее ожидаемого;
- модель вычислительно тяжелее простого интерполятора и обучается при запуске;
- revealed gaps старого test не имеют надёжно известного sensor source;
- модель не заменяет модуль аномалий или сервис сбора данных;
- v9 с увеличенным числом деревьев отклонена по фактическому leaderboard.

## Защита от утечки

Текущие hidden-ключи исключаются из donor context при построении признаков.
Удалённые организаторами climatology-поля принудительно не используются.
Опубликованные старые target применяются как исторические наблюдения других рядов,
а не как ответы текущего replacement test.
