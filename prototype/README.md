# VIGOR — интерактивный прототип

VIGOR — веб-интерфейс мониторинга вегетационной динамики полей. Прототип показывает основной пользовательский путь из задания Космохакатона: выбор территории, просмотр спутниковой карты, исходного и восстановленного NDVI, обнаруженной аномалии и её интерпретации с погодным контекстом.

## Что реализовано

- три переключаемых дизайн-концепта на одном наборе данных;
- карта с полигонами, зоной риска, слоями NDVI / спутник / влажность и датами;
- список полей, поиск, фильтр требующих внимания и карточки статуса;
- график наблюдений, восстановленных значений и климатической нормы;
- объяснение аномалии на основе NDVI, осадков, температуры и источников;
- создание задачи осмотра и демонстрационный экспорт отчёта;
- четырёхшаговый мастер добавления территории без ручной загрузки CSV;
- адаптивная компоновка для компьютера, планшета и телефона.

Все данные в прототипе демонстрационные. Настоящие API и ML-пайплайн подключаются на следующем этапе.

## Запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

Проверка production-сборки:

```bash
npm run build
```

## Стек и структура

- React 19, TypeScript, vinext;
- Tailwind CSS v4 и компоненты shadcn/Base UI;
- Recharts для временного ряда;
- `app/page.tsx` — состояние прототипа и пользовательские сценарии;
- `app/globals.css` — три визуальные системы и адаптивность;
- `public/field-map.jpg` — демонстрационная подложка карты.

## Дизайн-концепты

1. **Космос** — воздушный белый интерфейс, округлые формы и розово-коралловый акцент для эффектной демонстрации.
2. **Signal** — самостоятельная тёмная аналитическая система с контрастными сигналами и более строгой геометрией.
3. **Workspace** — плотный светлый рабочий интерфейс, ориентированный на ежедневную работу с картой и большим набором полей.

## Название и знак

Рабочее название **VIGOR** означает силу и жизнеспособность роста — ключевую характеристику, которую продукт оценивает по спутниковым данным. Оригинальный знак объединяет контур поля, букву V и импульс вегетационного сигнала. Перед коммерческим использованием потребуется отдельная юридическая проверка названия и товарных знаков.
